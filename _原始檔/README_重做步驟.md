## 做法與注意
- 內頁、四季圓窗、一頁拆解都直接用印刷檔（第 N 天正面＝PDF 第 2N 頁，裁掉 3mm 出血）。實拍照片和毛片裡的內頁是打樣，版面跟正式品略不同，動圖沒有換頁。
- 丁丁用「調色對齊麻豆」版本，再加彩度 1.45、對比 1.05（規範）。
- 受眾卡沒有四張都用麻豆：KOC、丁丁、麻豆兩張。KOC 原片多半壓了字幕，張嵇宇只裁字幕上方；高楉棠、林莛穎的字壓在日曆上沒用。
- 內頁卡片比照幹話 v12 縮小（132 寬）。
- 沒做「送禮範例」（幹話 v13 新加的外盒區）：鮮花的外盒只在 KOC 劉威頤開頭出現 1 秒，上方壓字。
